# RouteLog frontend

Vite + React 19 + TypeScript + Tailwind v4 + MapLibre (react-map-gl) + lucide-react.

```bash
npm install
npm run dev      # http://localhost:5173, proxies /api to 127.0.0.1:8000
npm run build    # type-check + production build
npx oxlint
```

- `VITE_API_BASE_URL`: backend origin. Leave it empty to use the same origin (Vite proxy or Vercel `/api/*` rewrite).
- `?demo=1` loads a mock Chicago → Denver → Los Angeles plan with an offline API client, so you can review the UI without the backend. `?demo=restart` loads a trip that needs a 34-hour restart.
- `src/types/api.ts` is the shared API contract. `src/components/logsheet/` holds the FMCSA log-sheet SVG.
- `src/mocks/samplePlan.ts` is generated by a simulation of the SPEC HOS algorithm. It is lazily loaded and never ships in the main bundle.
